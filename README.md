# TaskFlow – Task Management System

## Project Overview
TaskFlow is a web-based task management application designed to help users organize, manage, and track their daily activities efficiently.

The application provides a simple and user-friendly interface with a modern dark theme. Users can create tasks, update existing tasks, delete tasks, set priorities, and monitor their task completion progress.

## Features
- Add new tasks with titles and descriptions.
- Edit existing tasks.
- Delete unwanted tasks.
- Set task priorities: Low, Medium, and High.
- Assign due dates to tasks.
- Mark tasks as Pending or Completed.
- Search tasks by title.
- Filter tasks based on their status.
- Dashboard displaying total, pending, and completed tasks.
- Progress bar showing task completion percentage.
- Local Storage to save tasks in the browser.
- Responsive user interface.

## Technologies Used
- HTML5 – Application structure.
- CSS3 – Styling and responsive design.
- JavaScript – Application functionality and logic.
- Browser Local Storage – Data persistence.

## How to Run the Project
1. Download or clone the project.
2. Open the TaskFlow folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Add tasks and manage them using the dashboard.
5. Open the test files inside the `tests` folder to run the testing activities.
